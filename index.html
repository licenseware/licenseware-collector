Product Overview

What is LICENSEWARE Collector?
A lightweight agent that collects system and software inventory data from your servers and securely transmits it to the LICENSEWARE ™ platform for software license compliance analysis.
🖥️

Operating System Compatibility

🐧

Linux

  • x86_64 (64-bit) only
  • systemd required
  • RHEL, Ubuntu, Debian, etc.
🪟

Windows

  • x86_64 (64-bit) only
  • Windows 7 SP1+ (Desktop)
  • Windows Server 2012 R2+
🍎

macOS

  • Intel & Apple Silicon
  • macOS 10.15+
  • launchd service
⚠️ Legacy Windows Support
Windows 7 SP1 and Windows Server 2012 R2 are supported but have reached Microsoft end-of-life. We recommend upgrading to supported operating systems.
🌐

Installation Guide

1

Get Your Token

  1. Go to app.licenseware.io and sign in
  2. Navigate to LC App and go to API Keys Tab
  3. Click Create Key, configure it, and copy the token
2

Download & Register

Download the collector agent from the Collector app in Licenseware. Run with elevated privileges.

Linux / macOS
sudo ./licenseware-collector register --token YOUR_TOKEN
Windows (Admin)
.\licenseware-collector.exe register --token YOUR_TOKEN
