Product Overview

What is Licenseware Collector?
A lightweight agent that collects system and software inventory data from your servers using OSQuery, then securely transmits it to the Licenseware platform for software license compliance analysis.
🖥️

Operating System Compatibility

🐧

Linux Software Inventory Agent

  • x86_64 (64-bit) only
  • systemd required
  • RHEL, Ubuntu, Debian, etc.
🪟

Windows Software Inventory Agent

  • x86_64 (64-bit) only
  • Windows 7 SP1+ (Desktop)
  • Windows Server 2012 R2+
🍎

macOS Software Inventory Agent

  • Intel (x86_64) & Apple Silicon (ARM)
  • macOS 10.15+
  • launchd service
⚠️ Legacy Windows Support
Windows 7 SP1 and Windows Server 2012 R2 are supported but have reached Microsoft end-of-life. While the collector will function on these systems, we recommend upgrading to supported operating systems for security compliance.
🌐

API Endpoints for License Data Collection

All communication uses HTTPS with Bearer token authentication.

Method Endpoint Purpose Frequency
POST /licenseware-collector/agent/register Register agent with system information Once (at installation)
GET /licenseware-collector/agent/configs Fetch remote configuration overrides Every 30 minutes
GET /licenseware-collector/agent/catalogs Retrieve query catalogs to execute Every 30 minutes
POST /licenseware-collector/agent/ingest Upload collected inventory data (JSON) After each collection cycle

Installation Guide for License Compliance Agent

1

Get Your Token

  1. Go to Licenseware and sign in (or register a new account)
  2. Navigate to the Licenseware Collector application
  3. Navigate to the API Keys tab
  4. Click Create Key to create a new agent token
  5. Copy the token, you'll need it for the next step
🔐 Keep your token secure! It grants access to register agents under your account.
2

Download the Collector

Download the appropriate binary for your operating system from the Licenseware Collector releases page or your Licenseware dashboard.

3

Register the Agent

Run the registration command with elevated privileges. This will install dependencies, configure the service, and register with Licenseware.

Linux / macOS
sudo ./licenseware-collector register --token YOUR_TOKEN
Windows (Run as Administrator)
.\licenseware-collector.exe register --token YOUR_TOKEN
✓

Done! The Collector is Running

The registration process automatically:

  • Downloads and installs OSQuery
  • Installs the collector binary to the system path
  • Creates and starts a background service (daemon)
  • Registers the agent with your Licenseware account

You can verify the service is running with:

licenseware-collector status
